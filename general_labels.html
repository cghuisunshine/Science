General Labels on Image

1. Choose an image file (your worksheet PNG).
2. Choose a JSON file containing label texts.
3. Drag labels on top of the image to where you want them.

JSON format you can use

Two simple options are supported:

Option 1 – Just a list of texts

[
  "First label text",
  "Second label text",
  "Third label text"
]

They will appear stacked on the left, and you can drag them where you want.

Option 2 – Text plus optional positions

{
  "labels": [
    { "text": "First label",  "x": 30,  "y": 40 },
    { "text": "Second label", "x": 50,  "y": 120 },
    { "text": "Third label" }  // no x,y → stacked automatically
  ]
}
